# Agent build and composition trial

The current trial asks an agent to consume the repository's composer and construct an original world with a chosen feature subset. Tidepool is the kitchen sink: fictional coastal field notes, original graphics and all packs. A pocket world proves a small selection can build without the remaining modules, assets or permissions. A separately assigned agent authored [The Night Seed Library](../examples/seed-library/index.html): its own scenes, sources, cabinet diagram, night styling and tray-card evidence, selecting reader, sources and claims. Reproduce it with `node tooling/compose-world.mjs worlds/seeds --profile examples/seed-library/profile.json`.

Checks exercise actual algebra and refusal behavior: unknown or cyclic dependencies, conflicts, duplicate ownership, dangling feature mounts, selected-only source profiles, seed and budget preservation, evidence review, typed edits, source digests, programme receipts and tamper checks, media controls and reduced-motion rendering. Consumer builds check the physical closure rather than just descriptor metadata.

The current composition record is context/composition-coverage.json and evidence/composition. Earlier receipts under evidence/onboarding and evidence/framework describe the previous whole-expedition trials. Their findings remain useful but do not count as an independent confirmation of this architecture.

A separately assigned same-model agent supplies a software handoff test, not independent human usability or ecological validation. Tidepool content and motion are synthetic illustrations; they make no claim about a real coast.
