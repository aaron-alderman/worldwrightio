# Context for agents

Read the layers, then select the necessary route to the person’s requested result. The homepage explains why. The docs explain how. The starter runs. The reference library preserves the initial breakdown.

## Read first

AGENTS.md defines source ownership. docs/start.md provides the human handoff and commands. docs/architecture.md distinguishes meaning, composition, presentation and mechanisms. docs/lightning.md names necessary links and their failure conditions.

## Machine-readable entry points

context/project.json records purpose, paths and commands. context/features.json records reference modules, statuses, hashes, queries, operators and literal calls and ports. context/lightning.json records the dependency chain. templates/feature.json is the extension contract. templates/world/source/upstream.json pins copied mechanisms.

## A useful agent outcome

Return a working world, exact editable owners, commands actually run, observed results and narrow limitations. Ask for missing purpose or content. Do not invent personal history, testimonials or research evidence. Keep alternative compositions available.

## A useful contribution

Report missing schemas, unexpected dependencies or reproducible refusals with exact paths and commands. One causal run remains one evidence family. A contribution does not automatically change scientific status or authority.

The tested core is available now. Wider feature portability, independent agent onboarding and a complete humane authoring language remain open. Preserve those gaps when handing context to the next agent.
