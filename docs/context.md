# Context for agents

Read the layers, then select the necessary route to the person’s requested result. The homepage explains why. The docs explain how. The starter runs. The reference library preserves the initial breakdown.

## Read first

AGENTS.md defines source ownership. docs/start.md provides the human handoff and commands. docs/templates.md distinguishes the small reader from the full expedition composition. Read the created template's README for its concrete schema. docs/architecture.md separates meaning, composition, presentation and mechanisms. docs/lightning.md names necessary links and failure conditions.

## Machine-readable entry points

context/project.json records purpose, paths and commands. context/features.json maps initial modules to concrete recipes under templates/features. context/extraction.json records the current input/native/runtime closure, schema observations, grants and successor dependencies. context/lightning.json records the dependency chain. context/agent-trial-protocol.json fixes the different-world trial criteria. templates/feature.json remains the extension contract for new features. Each template's reuse manifest pins its copied mechanisms.

## A useful agent outcome

Return a working world, exact editable owners, commands actually run, observed results and narrow limitations. Ask for missing purpose or content. Do not invent personal history, testimonials or research evidence. Keep alternative compositions available.

## A useful contribution

Report missing schemas, unexpected dependencies or reproducible refusals with exact paths and commands. One causal run remains one evidence family. A contribution does not automatically change scientific status or authority.

Use the complete expedition to reuse the bounded initial feature set. Record actual checks and browser observations separately from the existence of a recipe. The agent trial is a transfer test inside this software task/model family; independent human usability, a complete humane authoring language and features beyond this declared scope remain separate work.
