# The algebra as a feature library

The initial personal expedition has 36 JSON algebra modules and 327 named queries. They are preserved byte-for-byte under reference/algebra, with SHA-256 identities and status in context/features.json. The catalogue below comes from that manifest.

## A working core

The starter includes derived expression definitions, lowering, fact indexing, model and effect admission, the language compiler, HTML serialization and CSS projection. Its world process demonstrates identities, relations, attributed sources, composition, navigation, source disclosure and receipt-bearing execution.

## A common extension contract

Each initial feature has a concrete contract under templates/features, identifying its runnable module, fact owners and selectors, dependency closure, runtime grants, projection, correction path and behavioral checks. The full expedition is the supported composition unit. The immutable original snapshot and its hash stay distinct from the current executable template.

Use templates/feature.json for additional capabilities. Existing process JSON executes through Temple lowering and admission. Each new feature needs a successful projection, a refusal and preservation checks.

## Richer features in the initial world

Reader models and activities retain scientific-example boundaries. Microsite modules supply project introductions, visual expression, motion and media. Atlas modules supply spatial navigation and remembered visits. Source presentation makes definitions readable. Encounter modules demonstrate contracts, projections and checked session edits. Authoring governs staged source changes and stale-source refusals. Publication, gateways and front doors join these into a personal expedition.

The expedition carries the source facts, assets, native effects and tests these features need. Its world framing is editable source; the Temple, Sourcery and Claimipedia examples remain attributed educational subsystems. Recipes show how the features participate in a new world rather than requiring another person's identity.

## Catalogue scope

Every JSON module in the captured personal expedition algebra directory is included. Literal calls and ports are retrieval aids; dynamic calls and semantic dependencies still need review. This does not enumerate every feature of the wider Sourcery platform or every possible Temple expression.
