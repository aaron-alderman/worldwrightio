# Feature library

The current reusable units are packs. Choose a subset, configure its source facts and compose its views inside a world. See [compose features](composition.html) for the pack list and commands, and context/composition-coverage.json for the coverage record.

The generated composition receipt records the selected closure, file hashes, modules, assets, output owners and effect grants. Unselected features do not contribute these to a generated world.

The historical module catalogue below preserves attribution and the original whole-expedition contracts. A historical JSON module by itself is not an independent package. Its current pack mapping and behavioral evidence are recorded separately; new UI alone does not establish equivalence.
