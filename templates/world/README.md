# Your first world

This standalone starter uses the same Temple seed, fact indexing, operator
lowering, admission and HTML projection as the initial Aaron Alderman expedition.
It needs Node 22 or later and no package installation or surrounding checkout.

Run `npm run build`, `npm test`, then `npm run dev`. Open the printed localhost URL.
Publish the generated dist directory using your chosen static host.
The build stages fresh output: failures preserve the last accepted world and
successful rebuilds remove pages that no longer belong to the source.

Edit source/world.rel to change the identity, places, readings, choices and sources.
Edit source/presentation.rel for presentation. Edit algebra/world.process.json for
composition and validation. Output and build receipts in dist are disposable.

The example is an imaginary field notebook. Its source note is an example, not
research evidence. Replace it with your own attributed material and boundaries.
All navigation and source disclosure work without JavaScript. Browser effects,
checked source edits and richer media are optional extractions described in the
Worldwright hub; this starter does not silently enable them.

See source/upstream.json for exact copied mechanism hashes. Changing the native
kernel or its budget is outside ordinary content authoring. A build receipt
records source identity and execution; it does not certify the truth of content.
