Source identities and boundaries
This is a live explanatory fixture, not the authoring bootstrap or a complete mainframe. Presentation source is HTML/CSS; session and interface behaviour are process algebra; the existing algebra owns the language semantics and source patches. The unchanged Temple kernel and existing algebra run locally in a Web Worker. Reloading starts a fresh example. Hashes and source links identify the supplied starting snapshot; candidate edits and their basis revisions appear in the return-path receipt.
