# Worldwright.io

The supporting platform for worlds of ideas. The landing page introduces the idea, its first personal expedition and the current limits of the authoring tools.

GitHub Pages publishes this static repository with `.github/workflows/pages.yml`. `index.html`, `landing.css` and `mark.svg` define the current landing page. Older explanatory pages remain at their existing paths. The custom domain is worldwright.io; the personal expedition lives at aaronalderman.com.
