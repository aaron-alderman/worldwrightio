# Core

The mandatory neutral world and source-defined document shell. Own identity is in source/world.rel: world title, description, purpose; optional kicker, image, imageAlt, entryLabel. Presentation is ordered StyleRule/Declaration REL in source/presentation.rel. Keep a visible :focus-visible rule.

FeatureBlock facts select feature, placement (home or a declared Place), and unique positive integer order; gaps are allowed. Each selected renderable feature can mount once per placement. Unknown features, unavailable views, invalid placements and duplicate orders refuse. Scripts are isolated ES modules.

The exact seed and 20,000,000 build budget stay unchanged. Generic value, file and HTML/CSS mechanisms do not decide feature selection or editorial meaning.
